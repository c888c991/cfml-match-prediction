# CFML 赛事结果预测

> 从原始数据采集，到可复现的滚动回测：一套完整的体育赛果预测链路。

一款手游职业联赛（CFML）的历史比赛数据采集、特征工程与胜负预测。目标很朴素——**能不能只用赛前就知道的信息，把胜负预测得比"猜胜率高的一方"更准。**

数据来自联赛官方数据服务商的开放接口，无需登录、无需截屏。

---

## 实测结果

回测口径：严格滚动前向（只用当天之前的比赛训练，每 50 场重训一次），**2,119 个预测点 / 815 场比赛**。

| 指标 | 数值 |
|---|---|
| 命中率 | **73.7%** |
| 基线：随机猜（50/50） | 51.6% |
| 基线：永远猜历史胜率高的一方 | 66.9% |
| 对数损失（越低越好） | 0.543 |
| 基线对数损失 | 0.693 |
| 仅用赛前信息（不含阵容） | 72.0% |

**概率校准检验**（模型说 X% 的时候，实际发生了多少）：

| 预测区间 | 样本数 | 实际胜率 |
|---|---|---|
| 40%–50% | 312 | 47.1% |
| 50%–60% | 486 | 56.4% |
| 60%–70% | 402 | 64.4% |
| 70%–100% | 226 | 78.2% |

各档偏差都在 3 个百分点以内。**这一步很重要**——如果校准不过关，模型给的百分比就不能当概率用，只能拿来排序。

## 几个值得说的技术点

### 1. 队名归一化：19 种写法 → 11 支队

原始数据里同一支队伍有多种写法：

```
BS  /  白鲨  /  白鲨.斗鱼          → 同一支队
R.LGD                              → LGD
AG                                 → 成都AG
```

**不做归一化，胜率统计全是错的**——同一支队被拆成三份，每份样本量都变小，实力估计失真。这一步用 Pandas 做的映射表 + 校验。

### 2. 扩展卡尔曼滤波（EKF）跟踪队伍实力

队伍实力不是常数，会随版本、阵容、状态漂移。用 EKF 做状态估计：

- 状态量：队伍实力评分 + 不确定性
- 观测：每场比赛的胜负结果
- 观测方程是 sigmoid（把实力差映射成胜率），非线性 → **做一阶泰勒展开线性化**

相比"固定半衰期手工衰减"的做法，EKF 的好处是不确定性能自动收敛：新队伍初期波动大，样本多了就稳下来。

### 3. 滚动前向回测，杜绝信息泄漏

这是最容易写错的地方。如果随机划分训练/测试集，模型会"看到未来"，回测数字漂亮但实际无效。

做法：

- 严格按时间切分，第 N 场只用第 1..N-1 场训练
- 每 50 场重训一次
- 前 80 场作为冷启动期（不参与评估）

`exp_cadence.py` 扫过重训节奏，结论是 80/50 已经是最优区间。

### 4. 整场胜率 ≠ 单局胜率（一个真实踩过的坑）

BO3 里，如果单局胜率是 p，整场胜率 = p²(3−2p)。两者差别很大：

```
整场 85%  →  单局其实只有 70.4%
```

早期版本直接拿整场胜率当单局用，导致比分分布隐含的整场胜率是 93.9%——**模型自相矛盾**。后来加了 `per_map_prob()` 用二分反解，才对齐。

### 5. 先手/后手与局间状态

射击类比赛的"上半场/下半场"换边，以及局间领先分数，都是强特征。`fit_round_market` 用贝叶斯平滑处理小样本格子（领先分 × 回合数的交叉表），避免某个格子只有 2 样本时给出极端概率。

## 怎么跑

```bash
pip install -r requirements.txt

# 1) 采集（首次全量约 10 分钟）
python fetch_raw.py

# 2) 建库
python build_db.py --report

# 3) 构造特征
python build_features.py

# 4) 赛前预测
python predict.py prematch --team-a "XROCK.快手" --team-b "EP.快手"

# 5) 回测 + 校准检验
python backtest.py
```

数据库与原始 JSON 未包含在仓库中（体积原因），按上面第 1、2 步自行生成即可。

## 已知局限

- **只覆盖 6 个赛季**，早期赛季数据稀疏，队伍实力估计冷启动偏差大。
- **不做版本更新建模**。游戏版本改动会改变强弱关系，模型只能靠 EKF 慢慢追上。
- **无选手级实时状态**（伤病、状态起伏）——数据源不提供。
- 命中率 73.7% 是在**该联赛历史数据**上的成绩，换赛区或换项目不一定可迁移。
